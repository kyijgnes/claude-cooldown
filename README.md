# 클로드 쿨다운

내 Claude 사용량(5시간·주간 한도)을 **컴퓨터**와 **폰**에 띄워 주는 작은 도구.

## ⬇️ 다운로드

**[👉 최신 버전 받기 (Releases)](https://github.com/kyijgnes/claude-cooldown/releases/latest)**

- 💻 **컴퓨터 (Windows)** — `claude-cooldown-v0.9.exe` (더블클릭)
- 📱 **폰 (안드로이드)** — `claude-cooldown-v0.9.apk` (설치)

> **Claude Code 에 로그인돼 있어야** 사용량이 보입니다.

## 쓰는 법

- **컴퓨터** — exe 더블클릭 → 작업표시줄 오른쪽에 막대. 클릭=새로고침 · 끌기=이동 · 우클릭=설정.
- **폰** — apk 설치 → PC 위젯 **우클릭 > 폰에서 보기 > 폰 연결…** 의 QR 을 폰 앱에서 찍기.

---

개발·빌드·서버 설정은 `CLAUDE.md`. 폴더: `pc/`(컴퓨터) · `android/`(폰) · `server/`(릴레이).
